Sales Prediction Using Python

Project Overview

This project focuses on predicting sales based on advertising expenditure across three advertising channels: TV, Radio, and Newspaper using Machine Learning.

Objectives

- Analyze the advertising dataset.
- Perform Exploratory Data Analysis (EDA).
- Understand the relationship between advertising expenditure and sales.
- Build and evaluate machine learning regression models.
- Identify the advertising channel that has the greatest impact on sales.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Machine Learning Algorithms

- Linear Regression
- Ridge Regression
- Random Forest Regression

Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

Visualizations

- Advertising expenditure vs Sales
- Correlation Heatmap
- Actual vs Predicted Sales
- Residual Plot

Conclusion

This project demonstrates how machine learning regression techniques can predict sales using advertising expenditure and help understand the relationship between advertising channels and sales.
