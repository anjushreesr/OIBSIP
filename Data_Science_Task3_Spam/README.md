Email Spam Detection Using Python

Project Overview

This project uses Machine Learning and Natural Language Processing (NLP) to classify SMS messages as Spam or Ham (Not Spam).

Objectives

- Load and explore the SMS Spam Collection dataset.
- Clean and preprocess text messages.
- Convert text into numerical features using TF-IDF.
- Train and compare machine learning classification models.
- Evaluate model performance.
- Test the model using custom messages.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Natural Language Processing (NLP)

Machine Learning Algorithms

- Multinomial Naive Bayes
- Logistic Regression
- Linear Support Vector Machine (SVM)

Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

Text Preprocessing

- Convert text to lowercase.
- Remove punctuation.
- Remove unnecessary stopwords.
- Apply TF-IDF vectorization.

Conclusion

This project demonstrates how Natural Language Processing and machine learning classification algorithms can identify spam messages and distinguish them from legitimate messages.
